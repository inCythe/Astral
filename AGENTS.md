Directory: `Scripts/Astral/` — the Astral uncapped, low-lag search overlay UI library for Roblox, plus its Studio preview port.

## Conventions

- Luau only. `.lua` / `.luau`; no Lua 5.1-only idioms (`continue`, `task.wait`, generalized iteration, string interpolation).
- Use `task.wait` / `task.spawn` / `task.delay`, never `wait` / `spawn` / `delay`.
- Services via `game:GetService("...")`. Guard every client-side service call that can fail (`HttpService`, `MarketplaceService`, `DataStoreService`).
- Scripts that touch a specific game should state the game and place ID in a header comment.
- Prefer small, single-purpose scripts over one large mega-script.
- Do not delete or overwrite an existing script without confirming — many are hand-tuned.
- Never put `Folder` instances inside `Model`s. Group with nested `Model`s instead.
- Give every `Model` a `PrimaryPart`; parts get unique, zero-padded names (`Trunk_01`, not `Part`).

## Studio preview (Edit mode)

The live UI is mirrored into Roblox Studio via `ReplicatedStorage/AstralPreview`:

- `Astral/Parts/Part_01..04` — `Astral.lua` split into string-fragment ModuleScripts (Roblox hard limit: `Source` < 200,000 chars; `Astral.lua` is ~580 KB).
- `Astral/LucideSource` — `LucideIcons.lua` injected as a fake `http_request` (Studio `game:HttpGet` / `HttpService:GetAsync` are unavailable).
- `Addons/SaveManager`, `Addons/ThemeManager` — real addon sources.
- `ExampleSource` — `Example.lua` with `game:HttpGet` imports replaced by injected arguments.
- `Runner` — `loadstring` + `setfenv` concatenation of the parts; unloads the previous library, destroys `Astral_*` ScreenGuis, reruns the example.

Refresh the preview:

```lua
require(game.ReplicatedStorage.AstralPreview.Runner)()
```

Runs in **Edit** mode via plugin context (`ReplicatedStorage.AstralPreview.Runner`), parented to `CoreGui`; no play session. `Players.LocalPlayer` exists (name `incyth4`) but has **no PlayerGui**; `CoreGui` is accessible and `ScreenGui` children render in the edit viewport.

Save the place (`Ctrl+S`) to persist `AstralPreview` (the CoreGui preview itself is not saved).

## Web preview (no Roblox)

`web/index.html` renders the same window in a browser: open it directly, or
`python -m http.server 8322 --bind 127.0.0.1 --directory web`.

- `web/window-spec.js` — the window as data, mirroring `Example.lua` (same
  property names: `Text`, `Default`, `Min`, `Max`, `Values`, `Side`, …).
- `web/astral.js` — spec → DOM renderer plus interactions (tabs, folding,
  sliders, dropdowns, key/colour pickers, search overlay, custom scrollbars).
- `web/astral.css` — library metrics and `Library.Scheme` tokens.
- `web/icons.js` — Lucide icon markup, generated by `web/build-icons.py`.
- Scaling mirrors `CalculateAutoBaseScale` / `SetDPIScale`: one uniform
  `transform: scale()`, 5% margins per side, auto mode capped to the fit.
- Deep links: `#device=932x430`, `#device=430x932&tab=Settings`.

No Roblox APIs and no `Callback` bodies: it is a visual/interaction reference,
not a runtime. Keep pixel values in sync with `Astral.lua` when elements change.
